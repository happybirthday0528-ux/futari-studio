# ふたりスタジオ

原曲 → SUNO → DAWでの仕上げ → YouTube投稿 までを、2人で進めるための共同制作環境です。

公開URL： http://rough-yame-05280.holy.jp/studio/

## ファイル構成
| ファイル | 役割 |
|---|---|
| `index.html` | 画面（見た目） |
| `js/app.js` | 画面の動き |
| `js/store.js` | データの保存先の切り替え（Firebase ／ このブラウザ） |
| `firebase-config.js` | Firebaseの設定（未設定ならローカルモード） |
| `firestore.rules` | Firestoreのセキュリティルール（コンソールに貼り付けて使う） |

## 2つのモード
- **ローカルモード**（`firebase-config.js` が `null`）… このブラウザの中にだけ保存。動作確認用
- **本番モード**（`firebase-config.js` に設定あり）… Googleログイン＋メンバー全員でデータを共有

## 本番モードで共有されるもの
- チャット（既読表示つき）
- 共有メモ（何個でも追加・検索・ピン留め・削除）
- 制作データ（候補の★・採用、コメント、修正指示、投稿チェック、クレジット）

「自分だけのメモ」は、本番モードでも常にこのブラウザの中にだけ保存されます。

## メンバーの追加
オーナーでログイン → 右上のアイコン → 「メンバー管理」で、相方さんのGmailアドレスを追加します。

## 更新の流れ
1. このリポジトリの `main` ブランチに変更を反映する
2. PowerShellで `deploy` を実行する（サーバー上で `cd ~/web/studio/ && git pull` が実行されます）
